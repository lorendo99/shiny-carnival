name: FixMate mobile visual direction
description: Why the mobile repair app borrows a finance mockup's aesthetics but not its features.
---

FixMate Mobile uses the selected dark cottagecore finance mockup only as a visual reference: warm umber, honey gold, sage, botanical detail, and serif display type. Keep its appliance-repair content, safety checks, evidence flow, and marketplace intact. The mobile appearance is dark-first rather than following the system theme for now.

**Why:** The user explicitly chose “Use its visual style, keep FixMate’s repair features” when asked whether to adapt or replace the app; the original selected mockup was a different Hearthstone finance product.

**How to apply:** For new mobile screens, carry through the warm visual hierarchy but never import finance account figures, banking actions, or Hearthstone branding. If mobile appearance selection is implemented later, treat the dark-first choice as the existing default rather than assuming system mode is already desired.
